# TownyCenturiesWars

Minecraft Spigot плагин для Towny - Система эпох развития и войн между нациями.

## Особенности

- **Система эпох**: 10 исторических эпох с постоянно развивающимися крафтами
- **Войны**: Система PvP войн между нациями с отслеживанием убийств
- **Оружейная**: Доступ к оружию и амуниции с эпохи Возрождения
- **Транспорт**: Покупка тракторов, поездов и современных транспортных средств
- **Интеграция с Towny**: Полная интеграция с плагином Towny
- **SkBee совместимость**: Поддержка скриптов через SkBee

## Эпохи развития

1. **Примитивный век** - деревянные инструменты, костёр, верстак
2. **Каменный век** - каменные инструменты, печь
3. **Бронзовый век** - золотые доспехи, удочка, поводок, компас
4. **Железный век** - железные доспехи, цепь, дверь, арбалет
5. **Расцвет** - алмазные доспехи, тракторы, поезда
6. **Раннее средневековье** - кузнец на спавне, кафедра, книги
7. **Развитое Средневековье** - чародейство (требует нации)
8. **Позднее средневековье** - незерит, динамит (требует нации)
9. **Эпоха возрождения** - оружейная, амуниция (требует нации)
10. **Атомный век** - современное оружие

## Команды

- `/century` - Открыть меню выбора эпохи
- `/century info` - Информация об эпохах
- `/wars declare <нация1> <нация2>` - Объявить войну
- `/wars list` - Список активных войн
- `/wars status <нация>` - Статус войн нации
- `/armory` - Открыть оружейную
- `/veh` - Открыть магазин транспорта

## Зависимости

- Spigot 1.20.1+
- Towny
- SkBee (опционально)

## Установка

1. Скачать JAR файл
2. Поместить в папку `/plugins/`
3. Перезагрузить сервер
4. Отредактировать конфиги при необходимости

## Разработка

```bash
mvn clean package
```

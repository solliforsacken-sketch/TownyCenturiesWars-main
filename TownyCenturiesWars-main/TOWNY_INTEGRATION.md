# Интеграция TownyCenturiesWars с Towny

## Описание

TownyCenturiesWars - это плагин для Spigot, который добавляет историческую систему развития эпох и войн в Towny.

## Установка

### Требования
- Spigot 1.20.1+
- Towny 0.100+
- SkBee (опционально)
- Vault (для экономики)

### Шаги установки

1. Скачайте TownyCenturiesWars.jar
2. Поместите в папку `/plugins/`
3. Перезагрузите сервер: `/reload`
4. Отредактируйте конфиги при необходимости

## Система эпох

### Доступные эпохи

1. **Примитивный век** (уровень 0)
   - Начальная эпоха для новых городов
   - Деревянные инструменты

2. **Каменный век** (уровень 1)
   - Требует: 32x Палка, 16x Пшеница, 64x Булыжник...
   - Каменные инструменты

3. **Бронзовый век** (уровень 2)
   - Требует ресурсы каменного века + золотые инструменты
   - Золотые доспехи и инструменты

4. **Железный век** (уровень 3)
   - Железные доспехи и инструменты
   - Печи и дополнительный функционал

5. **Расцвет** (уровень 4)
   - Алмазные доспехи
   - Доступ к тракторам и поездам
   - Бонус к производству ресурсов

6. **Раннее средневековье** (уровень 5)
   - Кузнец на спавне
   - Чары на книгах
   - Библиотеки

7. **Развитое средневековье** (уровень 6)
   - Расширенное чародейство
   - Новые возможности

8. **Позднее средневековье** (уровень 7)
   - Незеритовые доспехи
   - Динамит и взрывчатка
   - Требует нации

9. **Эпоха возрождения** (уровень 8)
   - **Доступ к оружейной** 🎯
   - Кроссбоу и боеприпасы
   - Полный набор оружия
   - Требует нации

10. **Атомный век** (уровень 9)
    - Современное оружие
    - Продвинутые технологии
    - Высшая техническая прокачка

### Переход между эпохами

**Команды:**
```
/century - Открыть меню выбора эпохи
/century info - Информация о всех эпохах
```

**Требования:**
- Город должен иметь достаточно ресурсов
- Жители города должны быть в городе
- Для некоторых эпох требуется город в нации

**Ресурсы проверяются в:**
- Сундуках города
- Банке нации (если город в нации)
- Личном инвентаре мэра

## Система войн

### Объявление войны

```
/wars declare <нация1> <нация2> [длительность]
```

**Параметры:**
- `<нация1>` - атакующая нация
- `<нация2>` - защищающаяся нация
- `[длительность]` - длительность в минутах (по умолчанию 60)

### Правила войны

- ✅ PvP принудительно включен между врагами
- ✅ Отслеживаются убийства
- ✅ Город может быть захвачен при поражении
- ✅ Требуется минимум эпоха Возрождения для объявления войны

### Команды войны

```
/wars list - Список активных войн
/wars status <нация> - Статус войн нации
```

### Отслеживание побед

- Каждое убийство врага = +1 очко
- Нация с 50+ убийствами побеждает
- Побежденная нация теряет город (если позволяет конфиг)

## Конфигурация

### Основной конфиг: `config.yml`

```yaml
centuries:
  enabled: true
  modes:
    auto_advance: false
    residents_for_advance: 10
  requirements:
    check_resources: true
    consume_resources: true
```

### Конфиг войн

```yaml
wars:
  enabled: true
  battles:
    allow_nation_wars: true
    default_duration: 60
  rules:
    force_pvp: true
    track_kills: true
    min_century_to_declare: "RENAISSANCE"
```

### Конфиг оружейной

```yaml
armory:
  enabled: true
  min_century_access: "RENAISSANCE"
  prices:
    crossbow: 5000
    diamond_helmet: 1000
    # ...
```

## Интеграция с Towny

Плагин полностью интегрирован с Towny и использует:

- **Уровни городов** - привязаны к эпохам
- **Уровни наций** - привязаны к эпохам
- **Банки** - для проверки ресурсов
- **Система войн** - дополнена отслеживанием эпох
- **Экономика** - через Vault

### Примеры интеграции

**Города по эпохам:**
```
Нива (Settlement) - Каменный век (1 житель)
Баронство фон Сирот (Village) - Железный век (6 жителей)
Град великий (City) - Расцвет (20 жителей)
Метрополь (Metropolis) - Возрождение (28+ жителей)
```

**Нации по эпохам:**
```
Ленд оф Старой земли (Nation) - Примитив (0 жителей)
Федерация новых земель (Nation) - Каменный век (10 жителей)
Царство Великого города (Kingdom) - Железный век (30 жителей)
Империя Возрождения (Empire) - Возрождение (50+ жителей)
```

## Команды

### Для всех игроков

```bash
/century                 # Открыть меню эпох
/century info            # Информация об эпохах
/wars list              # Список войн
/wars status <нация>    # Статус войн нации
/armory                 # Открыть оружейную (с Возрождения)
/veh                    # Магазин транспорта (с Расцвета)
```

### Для администраторов

```bash
/century admin reload   # Перезагрузить конфиги
/century admin set <нация> <эпоха>  # Установить эпоху
```

## Права доступа (Permissions)

```
townycenturies.use                  # Использование /century
townycenturies.wars.use             # Использование системы войн
townycenturies.wars.declare         # Объявление войны (только короли)
townycenturies.armory.use           # Доступ к оружейной
townycenturies.veh.buy              # Покупка транспорта
townycenturies.admin                # Админ права
```

## Решение проблем

### Эпоха не переходит
- Проверьте наличие ресурсов в сундуках города
- Убедитесь, что город имеет достаточно жителей
- Для некоторых эпох требуется город в нации

### Войны не работают
- Убедитесь, что обе нации имеют эпоху Возрождения или выше
- Проверьте, включена ли система войн в конфиге
- PvP должен быть включен в мире

### Оружейная не открывается
- Требуется эпоха Возрождения
- Проверьте разрешения (permissions)
- Город должен быть в нации
